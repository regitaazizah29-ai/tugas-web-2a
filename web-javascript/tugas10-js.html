Belajar DOM

paragraf 1 HTML DOM (HTML Document Object Model) adalah representasi berbasis objek dari struktur dokumen HTML yang memungkinkan bahasa pemrograman seperti JavaScript untuk membaca, mengubah, dan memanipulasi isi, struktur, serta gaya halaman web secara dinamis.

paragraf 2 DOM (Document Object Model) adalah antarmuka pemrograman (API) yang merepresentasikan dokumen HTML atau XML ke dalam suatu struktur berbentuk pohon (tree). Setiap elemen, atribut, dan teks di dalam halaman web dianggap sebagai sebuah objek atau node.
